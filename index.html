Standalone services — AWS

Product Engine

A rewrite–embed–rerank pipeline that maps natural-language queries to Würth product codes, using fine-tuned Qwen/Cohere embedding and reranking models behind a stateless HTTP endpoint — I worked on fine-tuning the embedder. ~100–200 live users.

Transcoding Service

Two-stage pipeline: an LLM extraction module parses unstructured docx, xlsx, pdf and csv files to natural-language product descriptions; a transcode module calls Product Engine via HTTP to map them to product codes. Output: structured Excel. Tested at 20k+ rows in production.

Conversational agents — agentsutils

Product Agent

Conversational agent (Rufus-style UX) using Product Engine as its core tool and querying live company databases (Impala, Databricks, Postgres) to answer product questions in natural language. ~50 live users.

SQL Agent

General-purpose NL→SQL agent with plan-and-execute architecture: a discovery module (info-schema queries + SQL knowledge-base RAG on qdrant) produces a structured plan; an execution module converges to the requested data. Covers Impala and Oracle SQL; packaged as a private GitLab module. ~50 live users.

agentsutils — shared orchestration framework

Private GitLab package used by all conversational-agent repos. Each agent defines its own scaffold and FastAPI harness; agentsutils owns the runtime: turns, sessions, DB persistence, in-RAM Redis cache, HITL, concurrency, and stateless APIs with short/long-term memory. Right now it backs two agents, and it's built to take on more without touching their code.
